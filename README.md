# Deep Learning Laboratory

[![License](https://img.shields.io/github/license/harisaravananm/Deep-learning-laboratory?style=for-the-badge)](https://github.com/harisaravananm/Deep-learning-laboratory/blob/main/LICENSE)

A collection of ten deep-learning experiments covering image processing, neural-network optimization, annotation, segmentation, object detection, image captioning, GANs, and sentiment classification.

## Features

- Clear project organization for learning, experimentation, or demonstration
- Project-specific workflows documented below
- Reproducible local setup instructions

## Tech stack

Python, deep learning, computer vision, NLP, RNN/LSTM, GANs, YOLO, UNet, and Mask R-CNN

## Quick start

Use Python 3.8 or later with at least 8 GB RAM. Each experiment is provided as a document with its implementation requirements and expected workflow. Install the libraries listed by the experiment before running its code.
